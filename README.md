# Lingua Bridge Family

Полный комплект сайта: главная страница, платформа со словарём поколений и быстрым поиском, AI-помощник, отзывы с серверным сохранением, форма заявок и административный раздел.

## Запуск локально

1. Установите Node.js версии 20.11 или новее.
2. Скопируйте `.env.example` в `.env`. В Windows можно выполнить `copy .env.example .env`, в macOS/Linux — `cp .env.example .env`.
3. Заполните `ADMIN_TOKEN` длинным случайным значением. Для генерации можно выполнить `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`.
4. Чтобы работал настоящий AI-чат, получите ключ OpenAI API и добавьте его в `OPENAI_API_KEY`. Укажите в `OPENAI_MODEL` модель, доступную вашему API-аккаунту.
5. Запустите `npm start` и откройте `http://localhost:3000`. Для сайта и сохранения отзывов/заявок дополнительные пакеты не нужны.

Без `OPENAI_API_KEY` сайт и остальные разделы запускаются, но сервер честно сообщает, что AI-чат не подключён. Подписка ChatGPT сама по себе не является API-ключом; API может тарифицироваться отдельно.

## Возможности

- **Быстрый поиск** ищет по названиям, ключевым словам и описаниям в выбранном разделе; фильтрация обновляется при переключении вкладок.
- **Словарь** содержит более 50 слов и выражений, определения и варианты уважительной реакции.
- **AI-помощник** отправляет сообщения через сервер на OpenAI Responses API; секретный ключ хранится в `.env`, а не в браузере. В истории запроса передаётся ограниченное количество предыдущих реплик, API вызывается с `store: false`.
- **Отзывы** сохраняются в `data/reviews.json` и публикуются после принятия сервером. За один час ограничено число попыток отправки с одного IP.
- **Заявки** сохраняются в `data/requests.json`. Если заполнить параметры SMTP в `.env`, дополнительно отправляется уведомление на указанный e-mail. Без SMTP заявки всё равно попадут в административный список.
- **Администрирование** доступно по адресу `/admin.html`. Введите `ADMIN_TOKEN`, чтобы просматривать заявки, менять их статус, скрывать/публиковать и удалять отзывы.

## Настройка уведомлений

Чтобы получать уведомления о новых заявках по e-mail, установите необязательный пакет командой `npm install`, затем заполните `CONTACT_NOTIFY_EMAIL`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS` и `MAIL_FROM`. Используйте пароль приложения или другой безопасный способ авторизации, разрешённый вашим почтовым провайдером. Проверьте доставку на тестовой заявке до публикации сайта. Без установленного пакета и настроенного SMTP заявки всё равно сохраняются и видны администратору.

## Развёртывание

Нужен хостинг, поддерживающий Node.js-процесс, переменные окружения и постоянное хранилище файлов. Добавьте все значения из `.env` в защищённые настройки хостинга и запустите `npm start`. Если нужны уведомления по e-mail, выполните `npm install` для установки необязательного пакета nodemailer. Включите HTTPS на стороне хостинга. Если хостинг использует эфемерную файловую систему, направьте `DATA_DIR` на постоянный диск; иначе отзывы и заявки могут исчезнуть при пересоздании окружения. Для большого публичного трафика вместо JSON-файлов рекомендуется managed database, резервное копирование, CAPTCHA/антиспам и модерация отзывов.

## Важные настройки перед публичным запуском

- Подтвердите личность, квалификацию, контакты, расписание и условия реальных психологов до того, как предлагать пользователям конкретную запись. Сейчас раздел принимает заявки на подбор/связь, но не подтверждает слот у специалиста.
- Добавьте на сайт опубликованную политику обработки персональных данных, сроки хранения заявок, контакты оператора и механизм удаления данных, соответствующие требованиям вашей юрисдикции.
- Замените краткие описания и тексты под нужды проекта. Не просите пользователей оставлять в отзывах чувствительные данные.
- Настройте лимиты и бюджет OpenAI API; секреты должны храниться только в окружении сервера.

## Проверка файлов

`npm run check` проверяет синтаксис JavaScript-файлов. Затем проверьте вручную отправку сообщения, публикацию отзыва, заявку, административный вход и e-mail-уведомление (если SMTP настроен).

## Быстрая публикация

Пошаговая инструкция для GitHub и Render находится в [`GITHUB_DEPLOY.md`](GITHUB_DEPLOY.md). В корне проекта есть `render.yaml` и скрипт `publish-to-github.ps1` для Windows. Ключ `OPENAI_API_KEY` добавляется отдельно в защищённых Environment-настройках Render после публикации, не в GitHub. GitHub Pages сам по себе не запускает Node.js-сервер; для ИИ, заявок и API нужно развернуть Web Service. Бесплатный Render не хранит локальные файлы постоянно, поэтому постоянное хранение пользовательских данных требует базы данных или постоянного диска на совместимом платном тарифе.
